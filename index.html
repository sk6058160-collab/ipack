Use as a Home Screen icon
  1. Open Shortcuts → + New Shortcut
  2. Add action Open App → pick the app
  3. Tap Share → Add to Home Screen
  4. Tap the small icon → Choose Photo → pick the saved icon
  5. Name it, tap Add. Hide the original app in App Library.

Set as wallpaper

  1. Tap Save → Save Image.
  2. Open Photos → the image → Share → Use as Wallpaper.
  3. Adjust and tap Add.

iOS doesn't allow apps to set wallpaper automatically. Tip: add iPack to your Home Screen (Safari → Share → Add to Home Screen) for full screen.
